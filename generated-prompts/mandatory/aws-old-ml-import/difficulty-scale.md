# AWS Question Difficulty Scale

Use difficulty to represent the cognitive complexity needed to answer the question correctly, not the importance of the topic.

| Difficulty | Label | Description |
| --- | --- | --- |
| `1` | Recall | Direct definition, service purpose, or obvious feature. One fact is enough. |
| `2` | Basic application | Select a known AWS service or ML concept for a straightforward requirement with few distractors. |
| `3` | Applied reasoning | Interpret a realistic scenario and distinguish between several plausible services, algorithms, or configurations. |
| `4` | Multi-factor design | Balance multiple constraints such as security, cost, scale, latency, governance, data type, or model behavior. |
| `5` | Expert judgment | Complex or nuanced architecture or troubleshooting scenario requiring several linked decisions and rejecting near-correct alternatives. |

Most questions in this AWS ML set should be `2` or `3`. Reserve `1` for unambiguous service-fact questions, `4` for scenario-based trade-offs, and `5` only when the answer genuinely requires advanced, multi-step reasoning.
