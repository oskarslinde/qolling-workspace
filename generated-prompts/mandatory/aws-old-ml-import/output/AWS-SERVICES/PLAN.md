# AWS-SERVICES Question Plan

## Objective

Build AWS service literacy for a learner who has not used AWS. Every current CLF-C02 in-scope service gets three distinct questions: foundational purpose recognition, requirement-based service selection, and differentiation from a related service.

## Difficulty policy

Most questions are difficulty 2-3. Difficulty 1 is intentionally rare; difficulty 3 is used for close service distinctions. The set includes a smaller number of higher-reasoning comparisons so the collection is not trivial.

## Quality policy

All questions use four unique answers, answer-level explanations, technical metadata, categories, authoritative AWS sources, and the question-generator family metadata. The inventory is based on the official CLF-C02 service-reference page and may require refresh when AWS changes that page.

## Generated contents

- Three questions for each service in `coverage-matrix.md`: purpose, selection, and comparison.
- Additional cross-service questions for commonly confused service families.
- JSON files grouped by the official service categories.
