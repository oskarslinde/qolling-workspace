# CLF-C02 Question Coverage Matrix

This matrix follows the current [AWS Certified Cloud Practitioner (CLF-C02) exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html). Domain weights describe scored-exam emphasis; they are not a required count for this 234-question local set. Current coverage estimates are based on a thematic review of the JSON files and are non-exclusive because one question can support multiple tasks.

| Domain / task | Exam weight | What should be covered | Current question coverage |
| --- | ---: | --- | --- |
| **1. Cloud Concepts** | **24%** | Cloud value, Well-Architected design, migration, and cloud economics | **~85 questions.** Broadly covered, with strong service and architecture recall; migration strategy and economics need more scenario depth. |
| 1.1 Define the benefits of the AWS Cloud | — | Global infrastructure, agility, elasticity, high availability, and value proposition | **~25 questions.** Availability, scalability, regions, and cloud benefits are represented. |
| 1.2 Identify design principles of the AWS Cloud | — | Well-Architected Framework pillars and how to distinguish them | **~24 questions.** Reliability, security, performance, cost, and operational principles appear; pillar trade-offs are limited. |
| 1.3 Understand migration benefits and strategies | — | AWS CAF, migration resources, replication, and Snowball-style migration choices | **~10 questions.** Migration is present but underrepresented compared with service definitions. |
| 1.4 Understand cloud economics | — | Fixed vs. variable costs, BYOL, rightsizing, automation, and economies of scale | **~30 questions.** Cost and pricing concepts are covered through governance/cost content; rightsizing and licensing scenarios need expansion. |
| **2. Security and Compliance** | **30%** | Shared responsibility, governance/compliance, IAM, and security capabilities | **~90 questions.** This is one of the strongest domains, although some questions remain service-fact recall. |
| 2.1 Understand the shared responsibility model | — | AWS/customer responsibilities and how the boundary shifts for EC2, RDS, and Lambda | **~15 questions.** Shared responsibility is represented; service-specific boundary comparisons are limited. |
| 2.2 Understand security, governance, and compliance concepts | — | Encryption, logs, Artifact, Inspector, GuardDuty, Shield, CloudWatch, CloudTrail, Config, and regional/industry compliance | **~35 questions.** IAM/KMS, logging, governance, and monitoring are strong; compliance-location scenarios need more coverage. |
| 2.3 Identify access management capabilities | — | Root protection, MFA, IAM users/groups/roles/policies, Identity Center, federation, access keys, and least privilege | **~30 questions.** IAM, roles, policies, root security, and least privilege are well represented. |
| 2.4 Identify components and resources for security | — | WAF, Firewall Manager, Shield, GuardDuty, Trusted Advisor, Marketplace products, and AWS security resources | **~35 questions.** WAF, security groups, Trusted Advisor, and security documentation are present; Firewall Manager and Marketplace are sparse. |
| **3. Cloud Technology and Services** | **34%** | Deployment/access, global infrastructure, compute, databases, networking, storage, AI/analytics, and other service categories | **~125 questions.** Broad service coverage is strong, but some categories are unevenly represented. |
| 3.1 Define deployment and operating methods | — | Console, CLI, APIs, SDKs, IaC, repeatable operations, and cloud/hybrid/on-premises models | **~20 questions.** IaC and access methods appear; deployment-model comparisons need more questions. |
| 3.2 Define AWS global infrastructure | — | Regions, Availability Zones, edge locations, high availability, multi-Region, and sovereignty | **~12 questions.** Regions/AZs and edge concepts are present but underweighted. |
| 3.3 Identify AWS compute services | — | EC2 instance families, ECS/EKS, Fargate, Lambda, Auto Scaling, and load balancers | **~25 questions.** Compute and serverless services are well covered. |
| 3.4 Identify AWS database services | — | Managed vs. self-managed databases, RDS/Aurora, DynamoDB, ElastiCache, DMS, and SCT | **~12 questions.** Core database distinctions appear; migration tooling is limited. |
| 3.5 Identify AWS network services | — | VPC components, gateways, ACLs, security groups, Route 53, VPN, and Direct Connect | **~20 questions.** VPC/security concepts are present; connectivity selection needs more depth. |
| 3.6 Identify AWS storage services | — | S3 classes/lifecycle, EBS, EFS, FSx, Storage Gateway, and AWS Backup | **~18 questions.** S3 and storage fundamentals are strong; file-service comparisons are thinner. |
| 3.7 Identify AI/ML and analytics services | — | SageMaker, Lex, analytics, Athena, Kinesis, Glue, and QuickSight use cases | **~25 questions.** QuickSight and ML services are covered; analytics service selection could broaden. |
| 3.8 Identify other in-scope service categories | — | EventBridge, SNS/SQS, Connect/SES, Support, Code tools/X-Ray, Amplify, WorkSpaces, and IoT | **~12 questions.** Messaging and developer tools appear; end-user, frontend, and IoT services are sparse. |
| **4. Billing, Pricing, and Support** | **12%** | Pricing models, budgets, cost tools, support plans, and assistance resources | **~40 questions.** Cost Explorer, Budgets, Trusted Advisor, and support concepts are present; support-plan scenario coverage is limited. |
| 4.1 Compare AWS pricing models | — | On-Demand, Reserved, Savings Plans, Spot, data transfer, and licensing | **~20 questions.** Pricing models appear; selecting among them for a workload needs more scenarios. |
| 4.2 Understand AWS billing and cost-management resources | — | Billing console, Cost Explorer, Budgets, Pricing Calculator, tags, and cost allocation | **~25 questions.** Cost Explorer and Budgets are represented; allocation/tagging is less visible. |
| 4.3 Identify AWS technical and account support | — | Support plans, Knowledge Center, re:Post, Trusted Advisor, and AWS Professional Services | **~15 questions.** Support resources are present but not a major focus of the current set. |

The main CLF-C02 gaps are migration strategies, global infrastructure, database/network selection, less-common service categories, and support-plan decisions. The set is strongest in security/IAM and core service identification.
