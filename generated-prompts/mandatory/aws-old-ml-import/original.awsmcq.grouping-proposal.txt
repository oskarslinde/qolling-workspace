Reference convention: Q001 is the first object in the source JSON array, Q002 the second, and so on.

Recommended working order
-------------------------
1. Resolve exact duplicates and malformed/ambiguous multiple-correct items inside each collection before content enhancement.
2. Repair factual accuracy, wording, answer cardinality, and distractors collection by collection.
3. Decide later whether the repaired collections should become separate import files; this proposal does not create them.

- 176 questions have other than one marked-correct answer; retain them only where multi-select behavior is intentional and supported.
